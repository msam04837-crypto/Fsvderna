# GovRegistry Desktop (Arabic RTL)

نظام مكتبي احترافي لإدارة حركة **السائقين** و**الزوار** داخل جهة رسمية (سفارة/مؤسسة حكومية) يعمل بالكامل بدون إنترنت.

## المزايا الأساسية

- تطبيق **WPF** لبيئة Windows مع واجهة عربية RTL.
- هندسة نظيفة بثلاث طبقات:
  - `GovRegistry.Wpf` (Presentation)
  - `GovRegistry.Core` (Business)
  - `GovRegistry.Infrastructure` (Data Access / SQLite)
- تسجيل دخول مع أدوار: `Admin`, `Supervisor`, `DataEntry`, `Viewer`.
- تسجيل محاولات الدخول الناجحة والفاشلة.
- إدارة السائقين: خروج/عودة، حالة نشطة، بحث، تصدير CSV.
- إدارة الزوار: دخول/خروج، الموجودون حالياً، بحث، تصدير CSV.
- Dashboard: مؤشرات لحظية + سجل آخر العمليات.
- Audit Log شامل (إنشاء/تعديل/عمليات تسجيل الحركة).
- نسخ احتياطي واستعادة لقاعدة البيانات المحلية.
- حماية الملاحظات الحساسة بـ DPAPI على Windows.

## تشغيل المشروع

> المتطلبات:
- Windows 10/11
- .NET SDK 8.0 أو أحدث مع دعم Windows Desktop

### خطوات التشغيل
1. افتح الحل `GovRegistry.sln` في Visual Studio 2022.
2. اجعل مشروع البدء: `src/GovRegistry.Wpf`.
3. شغّل التطبيق.

### بيانات الدخول الافتراضية
- المستخدم: `admin`
- كلمة المرور: `Admin@123`

## مكان تخزين البيانات

- قاعدة البيانات المحلية SQLite في:
  - `%LOCALAPPDATA%\GovRegistry\registry.db`
- النسخ الاحتياطية الافتراضية عند الضغط على زر النسخ الاحتياطي:
  - `%USERPROFILE%\Documents\GovRegistryBackups\`

## التقارير والطباعة

- التصدير الحالي بصيغة CSV (جاهز لفتح Excel مباشرة).
- الهيكلية الحالية تسمح بإضافة PDF/Print بسهولة داخل `IReportingService`.

## كيفية التوسعة

- لإضافة صلاحية جديدة: عدّل `UserRole` وآليات التحقق في ViewModels.
- لإضافة وحدة جديدة (مثلاً المركبات الرسمية):
  1. أضف نماذج وواجهات في `GovRegistry.Core`.
  2. أضف CRUD في `SqliteRepository`.
  3. أضف خدمات التطبيق في `GovRegistry.Infrastructure`.
  4. اربطها في واجهة WPF/ViewModels.

## ملاحظات إنتاجية

- ينصح بتفعيل **BitLocker** على الجهاز لحماية القرص كاملاً.
- يفضل إنشاء مهمة مجدولة يومية لأخذ نسخة احتياطية تلقائية.
- يمكن إضافة توقيع رقمي على ملفات النسخ الاحتياطية لمنع العبث.
